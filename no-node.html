🤖 Jinx Harness — Node.js not found

This package runs on Node.js, but no runtime was found on this server.

  1. CloudLinux hosts: ask your host to enable the Node.js Selector — no action needed afterwards, this page will just work.
  2. Any host: download node-v22-linux-x64-glibc-217.tar.xz from unofficial-builds.nodejs.org, rename it to node.tar.xz and upload it next to this file (same folder) via File Manager. Reload this page — the runtime self-extracts and boots automatically.
  3. Or install on a VPS / use a host with Node.js support (see README.md).
