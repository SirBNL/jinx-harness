## 🫵 مال خودته. همه‌ش.

| اپ‌های AI معمولی | Jinx Harness |
|---|---|
| اشتراک ماهانه | **صفر تومان — برای همیشه.** فقط هزینهٔ پرووایدر AI خودت، مستقیم |
| گفتگوهایت روی سرور آن‌ها | **سرور خودت، یک فایل SQLite.** کپی کن، بکاپ بگیر، پاکش کن — یک فایله دیگه |
| برند آن‌ها، محدودیت آن‌ها | **برند خودت** — اسم بذار، شخصیت بده، شبیه خودت کن |
| ممکنه قیمت رو بالا ببرن یا ببندنش | **کپی تو تا وقتی هاستت روشنه روشنه** |
| فقط یک پنجرهٔ چت | ربات تلگرام + پنل مدیریت وب + ۶۰+ ابزار |

و نه، به هیچ‌جا «خانه زنگ نمی‌زنه»: بدون آنالیتیکس، بدون ردیاب، بدون «آمار ناشناس». هوش مصنوعی دقیقاً به همون یک آدرسی وصل می‌شه که **خودت** تنظیم کردی — و هیچ‌جای دیگه.

## 🚀 نصب در ۳ قدم

> **اگه می‌تونی یه عکس آپلود کنی و یه فرم پر کنی، می‌تونی اینو اجرا کنی.**

**قدم ۱ — آپلود.** زیپ `jinx-harness` را از [**Releases**](../../releases/latest) دانلود کن.
در سی‌پنل → *File Manager* داخل `public_html` آپلودش کن و **Extract** بزن.

**قدم ۲ — لینک را باز کن.** آدرس `https://دامنه-تو/jinx-harness/` را در مرورگر باز کن.
بعد از چند ثانیه ویزارد راه‌اندازی ظاهر می‌شود.

**قدم ۳ — یک فرم را پر کن.**
- توکن ربات تلگرام — رایگان از [@BotFather](https://t.me/BotFather)؛ ویزارد همان‌جا زنده تستش می‌کند
- پرووایدر هوش مصنوعی — آدرس + کلید + مدل؛ تست زنده و لیست خودکار مدل‌ها
- اسم و شخصیت دستیارت

دکمهٔ **ساخت و شروع** — دستیارت زنده می‌شود و ویزارد یک‌بارمصرف برای همیشه قفل می‌شود.

پنل مدیریت: `https://دامنه-تو/jinx-harness/admin?t=…` (توکنش یک بار در پایان ویزارد نشان داده می‌شود).

بدون SSH. بدون خط فرمان. بدون Docker. هر هاست cPanel معمولی کافی است — این چیز دقیقاً برای همان‌جا مهندسی شده. (VPS دارید؟ [Plan B/C](README.md#plan-b--plan-c).)

| اگر به مشکل خوردی | راه‌حل |
|---|---|
| خطای `500` | File Manager → راست‌کلیک روی `index.cgi` → *Change Permissions* → **755** |
| صفحهٔ «Node.js not found» | از هاست بخواه Node.js Selector را فعال کند، یا `node.tar.xz` آپلود کن — [راهنما](README.md#where-does-nodejs-come-from) خودش ظاهر می‌شود |
| صفحهٔ 502 | `portable/data/logs/cgi-boot.log` را بخوان؛ تداخل پورت → `PORTABLE_PORT` در `portable/.env` |
| همه‌چیز سبز ولی ربات ساکت | پیام بده؛ `/health` را چک کن؛ `portable/data/logs/bot-DATE.log` |

## 🧠 کدوم هوش مصنوعی وصل کنم؟

هر چی که فرمت OpenAI بلد باشد — یعنی تقریباً همه. هر وقت خواستی از پنل وب عوضش کن، بدون ری‌استارت:

| می‌خواهی | وصل کن | چرا |
|---|---|---|
| کلاسیک و مطمئن | OpenAI · `gpt-4o-mini` | همه‌فن‌حریف |
| بهترین قیمت/کیفیت | DeepSeek · `deepseek-chat` | ارزان، در کد قوی |
| رایگان و سریع | Groq · `llama-3.3-70b-versatile` | پلن رایگان خوب |
| یک کلید، صدها مدل | OpenRouter | هر روز یک مدل دیگر امتحان کن |
| کاملاً رایگان و خصوصی | Ollama روی کامپیوتر خودت | حتی بدون اینترنت |

**هیچ پرووایدر و پیش‌فرضی وجود ندارد** — کلید هرگز از سرور خودت بیرون نمی‌رود. راهنمای کامل: [`docs/PROVIDERS.md`](docs/PROVIDERS.md).

## 🧰 برای کنجکاوهای فنی

*بقیهٔ این سند برای کسانی است که changelog را برای سرگرمی می‌خوانند. بقیهٔ آدم‌ها: همان سه قدم بالا کافی است.*

- **حلقهٔ ایجنت ۴۰ مرحله‌ای** با checkpoint/resume — کرش وسط کار یعنی از آخرین چک‌پوینت ادامه بده، نه از صفر
- **ساب‌ایجنت** — `delegate` برای تحقیق و کدنویسی موازی با بودجهٔ مستقل
- **سندباکس واقعی** — `run_js` روی QuickJS/WASM واقعی + `run_tests` و `run_project`
- **مرورگر مجازی** — `browser_navigate` / `click` / `type` / `scroll` / کراول کامل سایت
- **موتور ۲۴/۷ واقعی** — کارهای cron، یادآور، دیجست، حالت خودکار، پست کانال
- **پیام‌های غنی** — پانوشت، بخش‌های جمع‌شونده، دکمه‌های تعاملی، گالری
- **پنل وب** — آمار زنده، پرووایدرها، بکاپ، تست سلامت — با توکن ۶۴ کاراکتری hex
- **پایداری** — SQLite با WAL، بکاپ روزانه (۷ نسخه)، offset پایدار، ضدکرش، واچ‌داگ زامبی
- **بقا روی هاست اشتراکی** — بوت جداشده با setsid، پورت deterministic، fetch جایگزین خالص-JS برای هاست‌های با سقف حافظه (وقتی undici/llhttp-wasm می‌میرد شیم خودش را نصب می‌کند)، سندباکس fallback

معماری کامل، جدول مشخصات و جزئیات امنیت: **[README.md (English)](README.md#deep-dive--for-the-technically-curious)**

## سؤالات رایج

**به جایی وصل می‌شود؟** نه — بدون آنالیتیکس، بدون endpoint پیش‌فرض، بدون چک آپدیت.

**چند دستیار روی یک هاست؟** بله — هر کپی در پوشهٔ جدا؛ پورت‌ها خودکار و per-install.

**چرا تلگرام؟** غنی‌ترین API پیام‌رسانی mainstream است و نه دامنه می‌خواهد نه بررسی فروشگاه اپ — برای هاست اشتراکی ایده‌آل. پنل وب هم همه‌جا کار می‌کند.

**دیتای من کجاست؟** فایل‌های ساده زیر `portable/` روی هاست خودت: یک دیتابیس SQLite، لاگ‌ها، بکاپ‌ها. مال خودت.

**کلودفلر ورکرز؟** خارج از این بیلد (پروسهٔ دائمی، فایل‌سیستم، SQLite). ارزان‌ترین راه، همین هاست cPanel یا یک VPS کوچک است.

**به باندل پیش‌ساخته اعتماد ندارم.** منصفانه. لایهٔ wrapper — بوت، گیت‌وی، ویزارد، سلف‌تست، شیم fetch، یعنی تقریباً هر چیزی که باهاش سروکار داری — جااسکریپت خوانا و قابل ممیزی در همین ریپوست. موتور به‌صورت یک فایل پیش‌ساخته توزیع می‌شود (سورس TypeScript همین بیلد جزو ریپو نیست).

**بازنشانی کارخانه:** `portable/.env` را پاک کن (و اگر خواستی `portable/data/` را هم) → ویزارد دوباره باز می‌شود.

**آپدیت:** فقط `app.js`، `check.js`، `gateway.cjs`، `setup-server.cjs`، `fetch-shim.cjs` و `dist/` را جایگزین کن — دیتا و تنظیمات دست‌نخورده می‌ماند.
